# Archivo de sprints

Cada cierre conserva un dossier completo en `SPRINT-NN_<inicio>_<fin>/`: planes, LAUNCH y prompts,
fuentes/anexos, done, todas las incidencias del sprint, retrospectiva, USAGE y manifiesto de
traslado. RELEASE se incorpora después con sus propias fechas. Archivado no significa resuelto: las
pendientes enlazan su ficha viva. Otros proyectos leen esta carpeta para saber si un sprint está
cerrado (`DEPENDENCIAS.md`, condición `cerrado`).
