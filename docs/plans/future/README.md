# Sprints futuros

Sprints posteriores al de `next/`, uno por carpeta: `future/SPRINT-NN/SPRINT.md` (con sus planes
de grupo si ya los tiene), numerados correlativamente tras el de next. Misma cabecera canónica que
`next/SPRINT.md`. Al activar next (`sprint iniciar`), `future/SPRINT-(n+1)/` se promueve a `next/`.
Prepararlos no los activa; sus dependencias con otros proyectos van en `../DEPENDENCIAS.md`.
